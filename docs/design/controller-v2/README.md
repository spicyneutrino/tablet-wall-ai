# Controller v2 design folder

This folder keeps the design reference and the evidence for the controller redesign.

- `PLAN.md`: the final decision, process, and tradeoffs.
- `DESIGN.md`: the design system, layout, components, and states.
- `IMPLEMENTATION.md`: how the design maps onto the existing controller IDs, functions, and API.
- `REVIEWS.md`: the four design rounds and the cross-review scoring.
- `mockup/mockup.html`: the final design reference at 1440px, with fake data.
- `mockup/mockup-mobile.html`: the 390px design reference.
- `mockup/tokens.css`: the token sheet used by the reference.
- `screenshots/design-*.png`: rendered design references.
- `screenshots/implemented-*.png`: the real controller after implementation.

The mockup is a static design artifact. The working page is `frontend/controller/index.html` with `controller.css` and `controller.js`.
