              On the selected tablet, measure each ruler line with a physical ruler. Copy the full current labelled CSS span for each line. Long spans reduce extrapolation. The 200 px short-span option remains available on the tablet.

              Estimate the reading error for each measured line. It is propagated across the usable panel before saving. This does not establish a 2 mm accuracy claim.

              Choose which measurement to use

              Keep supplied writes nothing and preserves the current profile and mapping. Use ruler prepares a new calibration revision with these scales and errors. The supplied profile, old revisions and layout pins stay unchanged. Measure again discards this check.

              X is the browser’s horizontal axis; Y is vertical. Quarter turn maps these CSS axes into the native panel, and odd quarter turns exchange width and height. Each axis is measured independently. DPR does not change these measurements. Estimated panel profiles are not ruler verified; browser toolbars can inset the picture area.

              Advanced calibration fields

              Set quarter turn before checking the ruler. Review the propagated uncertainty. Measure the browser picture area’s inset from the panel origin for panel offsets; use 0 only when the viewport starts at the panel origin. Review these fields, then Save calibration.
